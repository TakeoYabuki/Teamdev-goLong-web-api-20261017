# Space now

ISSの現在位置と、選択した都市からの観測チャンスを確認できるWeb APIとデモアプリです。

RecursionのGo Web APIチーム開発課題として、3人で開発します。

## 実装予定の機能

- ISSの現在位置を2D地図に表示
- 観測都市の検索・選択
- 次回の可視通過とカウントダウンの表示
- 今後72時間の通過予測一覧
- 天気を加味した観測おすすめ度の判定
- 通過予測の絞り込み・ソート・ページ分け
- 見やすさ別の件数集計
- 通過1件の詳細表示

## 使用技術

- バックエンド：Go、net/http
- フロントエンド：HTML、CSS、JavaScript
- 地図：Leaflet、NASA GIBSの夜間画像

## 利用予定の外部API

- Where the ISS at?：ISSの現在位置
- N2YO：ISSの可視通過予測
- Open-Meteo：雲量予報

## 成果物
