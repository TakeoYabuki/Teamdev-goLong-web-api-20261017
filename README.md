# Space now

ISSの現在位置と、選択した都市からの観測チャンスを確認できるWeb APIとデモアプリです。

RecursionのGo Web APIチーム開発課題として、3人で開発します。

## 実装予定の機能

- ISSの現在位置を2D地図に表示
- 観測都市の検索・選択
- 次回の可視通過とカウントダウンの表示
- 今後72時間の通過予測一覧
- 天気を加味した観測おすすめ度の判定
- 通過予測の絞り込み・ソート・ページ分け
- 見やすさ別の件数集計
- 通過1件の詳細表示

## 使用技術

- バックエンド：Go、net/http
- フロントエンド：HTML、CSS、JavaScript
- 地図：Leaflet、NASA GIBSの夜間画像

## 利用予定の外部API

- Where the ISS at?：ISSの現在位置
- N2YO：ISSの可視通過予測
- Open-Meteo：雲量予報

## 成果物

## 実行環境

ローカル環境で実行します。

- Go 1.27.2 以上(`go.mod` に合わせています)

## 起動方法

以下は macOS・Linux(zsh・bash)の手順です。

1. 環境変数の設定ファイルを作ります。

   ```
   cp .env.example .env
   ```

   `.env` に N2YO の API キーを書きます。`.env` は Git に入りません。

2. 環境変数を読み込んで、サーバを起動します。

   ```
   set -a
   source .env
   set +a
   go run .
   ```

   Go は `.env` を自動では読み込みません。`set -a` と `source .env` で、シェルに読み込んでから起動します。

3. 起動したら、別のターミナルで動作を確認します。

   ```
   curl -i http://localhost:8000/api/health
   ```

   `{"status":"OK"}` が返れば起動できています。

4. デモ画面は、`web/index.html` をブラウザで直接開きます。

### 環境変数

| 名前 | 内容 | 省略したとき |
|---|---|---|
| `PORT` | サーバのポート番号 | 8000 |
| `N2YO_API_KEY` | N2YO の API キー。通過予測の取得に使います(実装中) | 通過予測を取得できません |

ポートだけを変えて起動する場合は、`PORT=8080 go run .` のように指定します。デモ画面は `http://localhost:8000` を呼ぶので、画面を使うときは 8000 のままにしてください。
